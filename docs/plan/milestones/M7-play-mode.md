# M7 — Play mode

- **Status:** not started — spec and tasks are written when M6 is done

## Goal

Play a whole setlist from start to end: move from song to song with one tap, a swipe or a key, always seeing what comes next.

## Try it

Start "Friday gig" on the tablet, play through all songs with the big next button, go back one song by swiping.

## Scope

- Play a setlist from the start or from a chosen song; play the (filtered) song list in order.
- Previous / next: big buttons in thumb reach, swipe left / right, keyboard arrows (laptop).
- Position (`3 / 12`) and the next song's title; Escape and a close button end play mode.
- Font size controls from M3; edit the current song.
- **One tap on stage** applies to every control.

## Out of scope

Bluetooth page-turner pedals (inbox), auto-scroll, metronome, timers.

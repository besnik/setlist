# M6 — Setlists

- **Status:** not started — spec and tasks are written when M5 is done

## Goal

Build setlists for a gig or a rehearsal and put the songs in the right order.

## Try it

Create the setlist "Friday gig", add three songs, change their order, remove one, rename the setlist.

## Scope

- Setlists screen: list of setlists with the number of songs; create, rename, delete (songs stay in the library).
- Setlist detail: songs in order with number and key; add songs (picker with checkboxes), move up / down, remove.
- Add a song to setlists from the song list.
- Deleting a song removes it from all setlists.
- One sample setlist on the very first start.
- Bottom navigation: Songs / Setlists.

## Out of scope

Drag-and-drop reordering, sets within a setlist, durations, sharing.

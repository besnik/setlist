# Roadmap

The **MVP** is milestones M1–M8: the first version the owner can really use at home and on a gig. Each milestone delivers one feature the CEO can try before the next one starts. Specs and tasks are written for the next milestone only (golden principle *Functionality first*).

| Milestone | Goal | Status |
|---|---|---|
| [M0 — Harness](milestones/M0-harness.md) | Rules, roles and knowledge base for agentic development | done |
| [M1 — Foundation and song list](milestones/M1-foundation-song-list.md) | Project skeleton, deployment, design foundation; list and search of sample songs | done |
| [M2 — Install and offline](milestones/M2-install-offline.md) | Installable PWA that works without a network | done |
| [M3 — Song view](milestones/M3-song-view.md) | Read a song full screen with highlighted chords and adjustable font size | done |
| [M4 — Song format](milestones/M4-song-format.md) | Decide and build the song format (ChordPro / plain text, B vs. H) | done |
| [M5 — Manage songs](milestones/M5-manage-songs.md) | Add, edit and delete songs; data saved on the device | not started |
| [M6 — Setlists](milestones/M6-setlists.md) | Build and order setlists; bottom navigation | not started |
| [M7 — Play mode](milestones/M7-play-mode.md) | Play a setlist song by song, one tap per action | not started |
| [M8 — Backup](milestones/M8-backup.md) | Export and import all data as one file | not started |
| M9 — User guide *(after the MVP)* | A simple, minimal (text first) user guide at `/setlist/guide/`, linked from the root of the website | not started |

Statuses: `not started` · `in-progress` · `done`.
